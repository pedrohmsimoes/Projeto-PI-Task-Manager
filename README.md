# 🏗️ BR Construtora – Painel de Obras

Este é um sistema completo de gerenciamento de obras voltado para construtoras. O painel permite acompanhar o andamento da obra, cadastrar materiais, atualizar status, controlar orçamento e apresentar informações visuais tanto para o administrador quanto para o cliente.

---

## 🔧 Tecnologias Utilizadas

- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Python (Flask)
- **Banco de Dados**: MySQL
- **Gráficos**: Chart.js
- **Deploy local**: Git Bash / VSCode

---


---

## 👥 Funcionalidades

### 🔐 Área do Administrador

- Visualizar todas as obras
- Cadastrar nova obra
- Editar orçamento da obra
- Atualizar status da obra
- Adicionar materiais
- Subir fotos do andamento da obra

### 👤 Área do Cliente

- Visualizar status e progresso da obra
- Ver fotos da construção
- Acompanhar cronômetro da obra
- Ver percentual do orçamento consumido

---

## 📷 Interface

A interface possui dois painéis:
- Painel Administrativo com controle completo da obra
- Painel do Cliente com visualização do progresso em tempo real
